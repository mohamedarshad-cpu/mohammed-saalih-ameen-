# RouteSafe AI - Frontend Client (Step 1 Foundation)

The frontend foundation is built with:
- React 19 + TypeScript
- Tailwind CSS (Modern AI/SaaS dashboard archetype)
- Leaflet + OpenStreetMap tiles (no API keys required)
- Lucide React icon suite
- Recharts (ready for analytical widgets)
- Reusable component architecture (`components/`, `types/`, `utils/`, `services/`, `data/`, `pages/`)

See `/src` for the complete source code and module implementations.
